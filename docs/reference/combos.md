# Power User Combos

Advanced workflows to maximize your productivity with Eldoria.

## 🎓 Thesis in 10 Minutes

Complete a thesis chapter draft in under 10 minutes.

### Steps

1. **Open Prompt Library** → Select "Thesis Chapter Generator"
2. **Fill Variables:**
   - Chapter: 2
   - Title: Literature Review
   - Topic: Your thesis topic
   - Key Points: "previous research, gaps, theoretical framework"
3. **Execute** → AI generates structured chapter
4. **Review & Edit** — Add your voice and citations
5. **Publish to Hub** → Saves to your thesis project

### Pro Tips
- Run Autonomous Researcher first to gather sources
- Use Integrity Guardian after to check originality

## 🔬 Research → Defense Pipeline

From raw research to presentation-ready slides.

### Steps

1. **Academic Hub** → Autonomous Researcher
2. **Enter Topic** → "Recent advances in heat transfer optimization"
3. **Wait for Results** → AI finds and summarizes sources
4. **Review Sources** → Add relevant ones to your project
5. **Generate Thesis** → Write chapters using the research
6. **Defense Deck** → Auto-generate presentation
7. **Export** → Download as PPTX

### Pro Tips
- Do research early in your project
- Let sources accumulate before writing
- Defense Deck uses your best content automatically

## ⚙️ System Deconstruction Workflow

For engineering students analyzing complex systems.

### Steps

1. **Open Prompt Library** → SAF System Deconstruction
2. **Fill Variables:**
   - System: "Combined Cycle Power Plant"
   - Description: "Gas turbine feeding steam turbine..."
   - Goal: "Improve overall thermal efficiency"
3. **Execute** → AI creates SAF blueprint
4. **New Canvas Created** → Visual component map
5. **Ask Follow-ups in Chat:**
   - "What's the critical path?"
   - "Suggest modifications to component X"
   - "Calculate cascading effects of Y change"

### Pro Tips
- Start broad, then drill into subsystems
- Use blueprints in your thesis methodology section

## 🔒 Code Audit Workflow

Security and performance review before deployment.

### Steps

1. **Open Prompt Library** → Code Audit
2. **Paste Code** or describe file location
3. **Select Focus:** Security / Performance / Both
4. **Execute** → Detailed audit report
5. **Review Issues** — Prioritize by severity
6. **Ask for Fixes:**
   - "Show me how to fix issue #3"
   - "Refactor this for performance"

### Pro Tips
- Audit before every major commit
- Save audit reports for documentation

## 📊 Competitive Analysis Express

Market research in 15 minutes.

### Steps

1. **Prompt Library** → Competitive Analysis
2. **Fill Variables:**
   - Industry: "AI Code Assistants"
   - Competitors: 5
   - Focus: "pricing, features, recent announcements"
3. **Execute** → Structured comparison report
4. **Chat Follow-up:**
   - "Who has the best pricing for startups?"
   - "What features are unique to X?"
5. **Export** → Use in business plan or thesis

## 🔄 Daily Workflow

Recommended daily routine for thesis writers.

### Morning (30 min)
1. Check Project Timeline for milestones
2. Run Integrity Guardian on yesterday's work
3. Quick Autonomous Research on current chapter

### Afternoon (Focus Time)
1. Write using Thesis Chapter Generator
2. Use Chat for clarifications
3. Publish to Hub regularly

### Evening (15 min)
1. Review Expert Verdict feedback
2. Update Timeline progress
3. Set tomorrow's goals
