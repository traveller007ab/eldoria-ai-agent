# Prompt Library

The Prompt Library is a collection of **structured prompt templates** that help you get consistent, high-quality AI outputs.

## Accessing the Library

1. Click the **📖 BookOpen** icon in the sidebar
2. Or press `Ctrl/Cmd + P` from anywhere

## Available Templates

### Engineering

#### SAF System Deconstruction
Break down any system into hierarchical components using the Strategic Analysis Framework.

**Variables:**
- `system_name` — Name of the system (e.g., "Rankine Cycle")
- `description` — System purpose and components
- `modification_goal` — What to optimize (optional)

**Best For:**
- Thermodynamic cycles
- Neural networks
- Supply chains
- Any complex system

---

### Academic

#### Thesis Chapter Generator
Generate structured thesis chapters following academic standards.

**Variables:**
- `chapter_number` — Which chapter (1-8)
- `chapter_title` — Title (e.g., "Literature Review")
- `thesis_topic` — Your research topic
- `key_points` — Topics to cover (optional)
- `word_count` — Target length (optional)

**Best For:**
- Literature reviews
- Methodology sections
- Analysis chapters
- Conclusions

---

### Business

#### Competitive Analysis Report
Generate market research on competitors in any industry.

**Variables:**
- `industry` — Market segment to analyze
- `num_competitors` — How many to compare (default: 3)
- `focus_areas` — Specific aspects to analyze (optional)

**Best For:**
- Market research
- Business plans
- Investment analysis

---

### Development

#### Code Security & Performance Audit
Comprehensive code review for vulnerabilities and optimization.

**Variables:**
- `code_context` — The code to audit
- `language` — Programming language (optional)
- `focus_type` — security, performance, or both (optional)

**Best For:**
- Pre-deployment reviews
- Legacy code audits
- Security assessments

---

## Using Templates

### 1. Select a Template
Browse by category or search by keyword/tag.

### 2. Fill Variables
Required fields marked with `*`. Auto-fill pulls from:
- Active project name
- Current canvas content
- Thesis vault data

### 3. Preview
Click **Preview** to see the composed prompt before sending.

### 4. Execute
Click **Execute** to add the prompt to your canvas and trigger AI generation.

## Favorites

Star frequently used templates for quick access:
1. Click the ⭐ icon on any template
2. Favorites appear in a dedicated section at the top
