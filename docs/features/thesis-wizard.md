# Thesis Wizard

The Thesis Wizard is your complete thesis management system — from outline to defense.

## Getting Started

1. Go to **Academic Hub** (🎓 in sidebar)
2. Click **Start New Project** or select existing
3. Follow the wizard steps

## Wizard Steps

### 1. Project Basics

Set up your thesis fundamentals:

| Field | Description | Example |
|-------|-------------|---------|
| Title | Full thesis title | "Optimization of Heat Transfer in Combined Cycle Power Plants" |
| Department | Your academic department | "Mechanical Engineering" |
| Supervisor | Primary advisor name | "Dr. John Smith" |
| Institution | University name | "Rivers State University" |
| Deadline | Target completion date | "2024-06-15" |

### 2. Chapter Structure

Define your thesis chapters:

- **Chapter 1:** Introduction
- **Chapter 2:** Literature Review
- **Chapter 3:** Methodology
- **Chapter 4:** Design & Analysis
- **Chapter 5:** Results & Discussion
- **Chapter 6:** Conclusion
- **Chapter 7:** References
- **Chapter 8:** Appendices

::: tip Custom Models
Use the **Model Selector** to choose from pre-built templates (RSU Mechanical Engineering, etc.) or create your own structure.
:::

### 3. Timeline

Set milestones for each chapter:

1. Click a chapter
2. Set target completion date
3. Track progress percentage
4. View in **Project Timeline** panel

## Generating Content

### Per-Chapter Generation

1. Select a chapter in the left panel
2. Click **Generate** button
3. AI creates structured content:
   - Proper headings (1.1, 1.2, etc.)
   - Academic tone
   - Citation placeholders
   - Transition paragraphs

### Using Prompt Library

For more control:
1. Open Prompt Library (📖)
2. Select "Thesis Chapter Generator"
3. Fill chapter details
4. Preview and execute
5. Publish to Hub

## Related Tools

### Defense Deck Generator

Auto-create presentation slides from your thesis:

1. Go to **Defense Deck** tab
2. Select chapters to include
3. Click **Generate Deck**
4. Export as PPTX (coming soon)

### Autonomous Researcher

Gather sources before writing:

1. Go to **Autonomous Researcher**
2. Enter research topic
3. Review found sources
4. Add to project bibliography

### Expert Verdict

Get AI feedback on your work:

1. Go to **Expert Verdict**
2. Select chapters to review
3. Receive structured feedback:
   - Clarity score
   - Academic rigor
   - Suggestions for improvement

### Integrity Guardian

Check your work for issues:

- **Originality Score** — Web comparison
- **Citation Check** — Format validation
- **Word Count** — Per-chapter tracking
- **Compliance** — Academic standards

## Best Practices

1. **Start with Research** — Use Autonomous Researcher first
2. **Outline Before Writing** — Fill in key points per chapter
3. **Generate in Batches** — One chapter at a time
4. **Review Everything** — AI output needs your voice
5. **Check Integrity Often** — Run Guardian after each chapter
6. **Export Regularly** — Save backups as DOCX
