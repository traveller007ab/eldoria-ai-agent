# Getting Started

Welcome to Eldoria AI IDE! This guide will help you get up and running in minutes.

## What is Eldoria?

Eldoria is a **sentient academic co-pilot** — an AI-powered IDE designed for:

- 📝 **Thesis Writing** — Structured chapter generation with academic standards
- 🔬 **Research** — Autonomous web research with source citations
- ⚙️ **Engineering Analysis** — SAF (Strategic Analysis Framework) for system deconstruction
- 💻 **Code Review** — Security and performance audits

## Quick Start (5 Minutes)

### 1. Access Eldoria

**Web App (Recommended):**
```
https://eldoria.netlify.app
```

**Desktop App:**
Download from the [Download Hub](/guide/installation#desktop) in the app.

### 2. Create Your First Canvas

1. Click the **Layout** icon in the sidebar (top-left)
2. Click **+ New Canvas** in the middle panel
3. Start typing in the editor pane

### 3. Use AI Assistance

**Chat Mode:**
- Type in the chat panel (right side)
- Ask questions about your content
- Request edits, summaries, or analysis

**Generate Mode:**
- Add content to your canvas
- Click the **⚡ Generate** button
- AI will produce output based on your content

### 4. Explore Prompt Library

1. Click the **📖 BookOpen** icon in the sidebar
2. Browse templates by category:
   - **Engineering** — SAF System Deconstruction
   - **Academic** — Thesis Chapter Generator
   - **Business** — Competitive Analysis
   - **Development** — Code Audit
3. Fill in variables and click **Execute**
