# APA 7th Edition Citation Guide

This guide provides comprehensive instructions for formatting citations and references according to the American Psychological Association (APA) 7th Edition, which is the standard for academic writing at Rivers State University.

## Quick Reference

### In-Text Citations

| Number of Authors | First Citation | Subsequent Citations |
|-------------------|----------------|----------------------|
| 1 Author          | (Smith, 2020)  | (Smith, 2020)        |
| 2 Authors         | (Smith & Jones, 2020) | (Smith & Jones, 2020) |
| 3-20 Authors      | (Smith, Jones, & Williams, 2020) | (Smith et al., 2020) |
| 21+ Authors       | List first 19, then ellipsis, then last | Same as first |

### Reference List Order
1. Alphabetical by author last name
2. A-Z order
3. Same author, multiple years: (2020a), (2020b)
4. No number ordering

## In-Text Citations

### Basic Format
- Author's last name + Year in parentheses
- Example: (Smith, 2019)

### Direct Quotes
**Short Quote (< 40 words)**
```
Smith (2019) stated that "the experiment yielded significant results" (p. 87).
```

**Long Quote (40+ words)**
```
According to recent research:

The experimental results demonstrate a clear correlation between the variables,
with statistical significance reaching p < .001 across all measured outcomes
(Smith, 2019, p. 156).
```

### Paraphrasing
When paraphrasing, include the author and year:
```
Research has shown that regular exercise improves cognitive function (Johnson, 2020).
```

### Multiple Sources
Separate with semicolons:
```
Previous studies support these findings (Brown, 2018; Davis, 2019; Wilson, 2020).
```

### Personal Communications
Emails, interviews, etc.:
```
(M. K. Johnson, personal communication, March 15, 2020).
```

### Religious Texts
```
The Bible (Matthew 6:9-13) instructs...
```

### Classical Works
First citation: (Aristotle, trans. 1944)
Subsequent: (Aristotle, trans. 1944)

## References by Source Type

### Journal Articles

**Standard Journal Article**
```
Author, A. A., Author, B. B., & Author, C. C. (Year). Title of article. *Journal Name, Volume*(Issue), pages. https://doi.org/xxxxx
```

**Example:**
```
Smith, J. A., & Jones, M. B. (2019). Effects of sleep on academic performance.
*Journal of Educational Psychology, 112*(3), 456-470. https://doi.org/10.1037/edu0000422
```

**Journal Article with DOI**
```
Author, A. A. (Year). Article title. *Journal Name, Volume*(Issue), pages. https://doi.org/10.xxx/xxxx
```

**Journal Article without DOI (Online)**
```
Author, A. A. (Year). Article title. *Journal Name, Volume*(Issue), pages. https://www.journalurl.com
```

**Newspaper Article (Online)**
```
Author, A. A. (Year, Month Day). Article title. *Newspaper Name*. https://www.url
```

### Books

**Single Author**
```
Author, A. A. (Year). *Book title* (Edition). Publisher.
```

**Example:**
```
Brown, L. S. (2018). *Critical thinking in the digital age* (2nd ed.). Academic Press.
```

**Two or More Authors**
```
Author, A. A., Author, B. B., & Author, C. C. (Year). *Book title*. Publisher.
```

**Chapter in Edited Book**
```
Author, A. A. (Year). Chapter title. In B. B. Editor (Ed.), *Book title* (pp. xx-xx). Publisher.
```

**Example:**
```
Williams, J. R. (2019). Climate change impacts on coastal communities.
In T. K. Miller (Ed.), *Environmental science in the 21st century* (pp. 45-67).
Science Publishers.
```

**E-Book**
```
Author, A. A. (Year). *Book title* (Version). Publisher. https://www.url
```

**Translation**
```
Author, A. A. (Year). *Book title* (B. C. Translator, Trans.). Publisher. (Original work published Year)
```

### Websites

**Webpage**
```
Author, A. A. (Year, Month Day). Page title. Site Name. https://www.url
```

**Example:**
```
National Institute of Health. (2020, January 15). Understanding clinical trials.
https://www.nih.gov/health-information/clinical-trials
```

**Online Report**
```
Organization Name. (Year). *Report title*. https://www.url
```

### Conference Materials

**Conference Paper (Published)**
```
Author, A. A., & Author, B. B. (Year). Paper title. In *Proceedings of Conference Name* (pp. xx-xx). Publisher.
```

**Conference Paper (Unpublished)**
```
Author, A. A. (Year, Month). Paper title. Paper presented at Conference Name, Location.
```

**Conference Poster**
```
Author, A. A. (Year, Month). Poster title. Poster session presented at Conference Name, Location.
```

### Theses and Dissertations

**Published Thesis/Dissertation (from Database)**
```
Author, A. A. (Year). *Title of thesis* (Doctoral dissertation or Master's thesis). Database Name.
```

**Unpublished Thesis/Dissertation**
```
Author, A. A. (Year). *Title of thesis* [Unpublished doctoral dissertation]. University Name.
```

### Other Sources

**Patent**
```
Inventor, A. A. (Year). Patent title (Patent Number). Source.
```

**Software**
```
Author, A. A. (Year). *Software title* (Version) [Computer software]. Publisher.
```

**Government Document**
```
Government Agency. (Year). *Title of document*. Publisher.
```

**Encyclopedia/Dictionary**
```
Entry Author, A. A. (Year). Entry title. In *Encyclopedia/Dictionary name* (Vol. x, pp. xx-xx). Publisher.
```

## Special Cases

### No Author
```
*Title of work*. (Year). Publisher or Source.
```

Alphabetize by first significant word in title.

### No Date
```
Author, A. A. (n.d.). Title of work. Publisher.
```

### Multiple Works by Same Author
```
Smith, J. A. (2018a). First title...
Smith, J. A. (2018b). Second title...
Smith, J. A. (2020). Third title...
```

### Secondary Sources
```
Original author as cited in secondary source:
According to Jones (as cited in Smith, 2020)...

Reference list:
Smith, J. A. (2020). Title of book. Publisher.
```

### Social Media
```
Author, A. A. [@username]. (Year, Month Day). Content of post [Type of post].
Platform. https://www.url
```

### Press Releases
```
Organization Name. (Year, Month Day). Title of release (Press Release No. xxxx). Publisher.
https://www.url
```

## Common Errors to Avoid

### 1. Missing DOIs
- Include DOI when available
- Use "https://doi.org/" format
- For old articles without DOI, include URL

### 2. Incorrect Author Formatting
- Last name first, then initials
- Use & instead of "and"
- Maximum 20 authors (et al. after 20)

### 3. Hanging Indent
- All references must have hanging indent (0.5 inches)
- First line flush left, subsequent lines indented

### 4. Italicization
- Journal names: Italics
- Volume numbers: Italics
- Book titles: Italics
- DOIs: Regular (not italicized)

### 5. Capitalization
- APA uses sentence case for titles
- Only capitalize first word, proper nouns, after colon
- Exception: Journal/book titles use title case

### 6. Ampersand vs. "and"
- Use "&" in parentheses and reference list
- Use "and" in running text

### 7. Retrieved from
- Only use for online sources that may change
- Otherwise, just include URL

## Examples by Field

### Engineering
```
Author, A. A. (Year). Title of paper. *Journal of Engineering, 10*(2), 45-58.
https://doi.org/10.xxx/eng.2020.001
```

### Medicine
```
Author, A. A., & Author, B. B. (Year). Title of clinical study.
*New England Journal of Medicine, 382*(15), 1432-1440.
https://doi.org/10.1056/NEJMoa2001017
```

### Social Sciences
```
Author, A. A. (Year). Title of study. *Journal of Social Science, 15*(3), 112-128.
https://doi.org/10.xxx/jss.2020.003
```

### Education
```
Author, A. A., Author, B. B., & Author, C. C. (Year). Impact of intervention.
*Educational Research Review, 25*, 78-95. https://doi.org/10.xxx/err.2020.005
```
